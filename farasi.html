MACHINE DETAILS

Machine Specifications

Machine Type CNC Router (Wood, MDF, Acrylic, Aluminium, Soft Metals)
Effective Working Area 2400mm x 1200mm (4ft x 8ft full-sheet capacity)
Frame Heavy-duty solid steel frame, welded and reinforced
Drive System Rack and pinion (X and Y axes) + ball screw (Z axis)
Guide System Precision linear guide rails
Spindle 2.2kW - 3kW VFD Water-Cooled or Air-Cooled Spindle
Controller DSP Controller / Mach3 compatible
Software Compatible Artcam, Vectric Aspire, AutoCAD, DXF, G-code
File Formats G-code, DWG, DXF, STL, PDF
Power Single-phase or three-phase 220V / 380V
Materials Hardwood, MDF, Plywood, Acrylic, Soft Aluminium, Forex, PVC
Speed Up to 15,000 mm/min rapid travel speed
Included Machine + delivery + installation + 2-day operator training + 6-month technical support
